# Landing Page — Mochila Transportadora para Mascotas (Burbuja 360°)

Landing page de conversión para el producto de la tienda Sofía Premium:
https://ventasproia.com/tienda/sofia-premium/producto/168

## Estructura
- `index.html` — página completa (hero, beneficios, galería, usos, specs, testimonios, FAQ, CTA)
- `assets/styles.css` — estilos (responsive, sin frameworks)
- `assets/app.js` — galería interactiva + animaciones al hacer scroll

## Ejecutar
```bash
python3 -m http.server 3000
```
Luego abrir http://localhost:3000
